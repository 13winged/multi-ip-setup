# Скрипты для настройки Multiple IP

Набор скриптов для автоматической настройки нескольких IP адресов на одном сетевом интерфейсе в Linux.

## 🚀 Возможности

- Автоматическая настройка multiple IP адресов
- Source-based маршрутизация
- Сохранение настроек через systemd
- Диагностика и мониторинг
- Автоматическое исправление проблем
- Обнаружение проблем на стороне провайдера

## 📋 Требования

- Linux (Ubuntu/Debian/CentOS/RHEL)
- Доступ root
- Multiple IP адреса от провайдера
- Базовые знания сетевых технологий

## 🛠️ Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/13winged/multi-ip-setup.git
```

## ⚙️ Конфигурация

### Автоматическое определение
Скрипты автоматически определяют конфигурацию вашей сети. Ручная настройка опциональна.

### Ручная конфигурация (если нужно)
Отредактируйте `config.env` или переменные в скриптах:

```bash
# Сетевой интерфейс (определяется автоматически)
INTERFACE="eth0"

# Основной IP и шлюз (определяются автоматически)          
MAIN_IP="192.168.1.100"
MAIN_GW="192.168.1.1"

# Подсеть для дополнительных IP
SUBNET="10.0.0.0/24"
START_IP=1
END_IP=254

# Диапазон таблиц маршрутизации
TABLE_START=1001
```

## 🔧 Ручные команды

Если предпочитаете ручную настройку или диагностику:

```bash
# Добавить IP адрес
ip addr add 10.0.0.1/32 dev eth0 label eth0:10

# Создать таблицу маршрутизации
ip route add default via 192.168.1.1 dev eth0 table 1001 src 10.0.0.1

# Добавить правило маршрутизации
ip rule add from 10.0.0.1 table 1001

# Отключить reverse path filter
sysctl -w net.ipv4.conf.eth0.rp_filter=0
```

## 🐛 Решение проблем

### Частые проблемы

1. **IP не маршрутизируются наружу**
   - Проверьте поддержку multiple IP у провайдера
   - Убедитесь, что IP не за NAT
   - Запустите `./diagnose-network.sh`

2. **Проблемы с подключением**
   - Проверьте правила firewall
   - Убедитесь в правильности таблиц маршрутизации
   - Протестируйте `curl --interface 10.0.0.1 http://ifconfig.me/`

3. **Ошибки скриптов**
   - Убедитесь, что запускаете от root
   - Проверьте имя интерфейса
   - Убедитесь, что IP адреса назначены

### Команды диагностики

```bash
# Проверить IP адреса
ip addr show dev eth0

# Проверить таблицы маршрутизации
ip route show table 1001

# Проверить правила маршрутизации  
ip rule show

# Тестировать подключение для каждого IP
curl --interface 10.0.0.1 http://ifconfig.me/
```

## 📊 Что делают скрипты

### setup-multi-ip.sh
- Создает бэкап текущей конфигурации
- Добавляет multiple IP адреса на интерфейс
- Настраивает source-based таблицы маршрутизации
- Конфигурирует правила маршрутизации
- Отключает reverse path filtering
- Создает systemd сервис для сохранения настроек

### diagnose-network.sh
- Проверяет системную информацию
- Проверяет конфигурацию интерфейса
- Тестирует таблицы и правила маршрутизации
- Тестирует подключение для каждого IP
- Обнаруживает проблемы SNAT (проблемы провайдера)
- Проверяет firewall и статус сервисов

### fix-routing.sh
- Исправляет сломанные таблицы маршрутизации
- Сбрасывает правила firewall
- Переприменяет конфигурацию маршрутизации
- Отключает ограничительные сетевые настройки

## ⚠️ Важные заметки

1. **Поддержка провайдера**: Ваш хостинг-провайдер должен поддерживать multiple routable IP
2. **Доступность IP**: Дополнительные IP должны быть назначены на ваш сервер
3. **Бэкап**: Всегда делайте бэкап перед изменениями сети
4. **Тестирование**: Тестируйте в непродакшн среде сначала
5. **Сохранение настроек**: Скрипты создают systemd сервис для настройки при загрузке

## 🛡️ Вопросы безопасности

- Скрипты включают примеры правил firewall
- Reverse path filtering отключен (требуется для multi-IP)
- Рассмотрите дополнительные меры безопасности для продакшн использования
- Мониторьте сетевой трафик при использовании multiple IP
